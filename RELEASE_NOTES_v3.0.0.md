# ENTITY v3.0.0 Release Notes

Released: 2026-09-23
Qualification: BTG internally qualified

ENTITY v3.0.0 introduces the provider-independent sovereign state and data-rights market architecture built around ENTITY, AUTHORITY, RIGHT, EVENT and VALUE.

## Major release components

- Universal Transaction Fabric and sovereign object lifecycle.
- Versioned profile architecture with schema immutability and negotiation.
- ENTITY Exchange Protocol (EEP) for trading rights in data.
- ENTITY Originator Participation Profile (EOPP).
- Market State Recovery Profile (MSRP).
- Privacy, dispute, recovery, federated-resolution, AI-delegation and physical-binding profiles.
- EEP JSON Schema and sealed valid/invalid conformance vectors.

## Release qualification

The release gate includes the complete v3 regression, EEP conformance vectors, reference/mirror convergence, adversarial authorization and concurrency campaigns, EOPP accounting/economic-integrity tests, destructive market recovery and a bounded 500-settled-trade load run.

This release does not claim external unrelated-party v3 interoperability or production exchange certification. Those remain explicit post-release qualification tracks.

See `docs/qualification/ENTITY_V3_0_0_RELEASE_QUALIFICATION_2026-09-23.md` and `ENTITY_V3_RELEASE_MANIFEST.json` for the evidence and claim boundary.
