# BTDU — Blackmore Technology Data Universe

ENTITY v3.4.2 adds BTDU as an additive governed information substrate. It does **not** replace or rewrite ADAM, ENTITY authority, the Genesis primitives, the market/economic lifecycle, or historical release semantics.

## Layering

- **ENTITY** remains the authority, identity, rights, provenance, verification and economic system.
- **ADAM v1.0 RC2** remains the pinned deterministic atom/bond/reaction state engine.
- **BTDU** provides universal byte atoms, recursive exact compounds, governed semantic/economic lineage, repository self-ingestion and bounded reasoning projections.
- **NIKI** may consume bounded BTDU projections; no authority transfers to NIKI.

The canonical BTG universe is bound to the cryptographic Entity `ent2-6eoiiztjyhmyh2tbr5psmofcduwvjledubhoiqwo6mjfoqkn6ica` (`shawn.blackmore.entity`). Human-readable aliases are not authority.

## Exact representation

Every BTDU-ingested object has two independently verifiable representations: exact content-addressed ADAM evidence and a deterministic recursive compound built from the 256 primitive byte atoms. Deep verification reconstructs both and requires the same SHA-256.

This is not a claim that BTDU beats conventional entropy compression. BTDU is a governed representation/lineage substrate; compression remains a separate concern.

## Economy and lineage

`DCO → INSTRUMENT → LISTING → DISCLOSURE → ORDER/RFQ/AUCTION → PRICE DISCOVERY → TRADE → CLEARING → SETTLEMENT → ENTITLEMENT → USAGE → DERIVED OUTPUT → ECONOMIC CONSEQUENCE`

Mirrored topology is evidence/lineage only. It does not create ownership, rights, royalties, settlement obligations or economic entitlements. Economic participation still requires explicit effective ENTITY terms. `automatic_protocol_royalty_bps` remains `0`.
