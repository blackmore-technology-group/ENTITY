# Sovereign Entity Network

This directory is an independent system root on <LOCAL_DRIVE>/ and is not part of Blackmore_Technology_Group.

## Core purpose
Create a self-owned digital entity platform where people, families, organizations, products, applications, communities, and future entity types can possess persistent cryptographic identities, host sites and apps, own their data, publish selectively, and communicate over a peer network.

## Architectural rules
1. An Entity is a persistent logical identity; it is not an IP address, domain, computer, process, or folder.
2. A Node is a runtime instance authorized to act for one or more Entities.
3. One physical computer may host many Nodes and effectively unlimited logical Entities.
4. Entities may move between hardware without changing identity.
5. Peer-to-peer communication is first-class; centralized relays are fallback transport only.
6. Public Internet/DNS support is a compatibility bridge, not the source of Entity identity.
7. User-owned data remains local or on explicitly authorized replicas unless intentionally published/shared.
8. Hosted sites and apps are services owned by Entities and do not require separate conventional hosting accounts.
9. BSIE holds authoritative world/entity state, NIKI interprets and reasons, and ADAM performs authorized actions.
10. Camera AR remains a first-class view; Dashboard AR and Remote Camera Projection are additional projection targets using the shared AR renderer.
